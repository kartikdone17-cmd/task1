# Aura — Modern AI Landing Page

A visually polished, responsive static landing page built with pure HTML5 and CSS3 (no external JavaScript dependencies).

## 🚀 Quick Start

1. Simply double-click **`index.html`** in this folder to open the landing page in any web browser (Chrome, Edge, Firefox, Safari).
2. Or right-click `index.html` -> Open with -> Your preferred browser.

---

## 📋 Features & Checklist Fulfilled

- ✅ **Fixed/Sticky Navigation Bar**: Glassmorphism frosted blur effect with logo, 4 navigation links, and CTA buttons.
- ✅ **Hero Section**: Eyebrow badge, gradient headline, subheadline, dual call-to-action buttons, trust indicators, and a responsive CSS dashboard preview.
- ✅ **Content Sections**:
  - **Capabilities / Features**: 6 feature cards with custom SVG icons and hover glow effects.
  - **Workflow / How It Works**: 3-step structured timeline cards.
  - **Testimonials / Social Proof**: 3 testimonial cards with 5-star badges and verified user avatars.
  - **Pricing Plans**: 3 tier cards (Starter, Pro with popular ribbon, Enterprise).
  - **Pre-Footer CTA Banner**: High-conversion call-to-action card.
- ✅ **Footer**: Multi-column links (Product, Resources, Company), social media links (X, GitHub, LinkedIn, Discord), and copyright notice.
- ✅ **Color Palette**: Consistent modern dark theme palette (Deep slate `#090d16`, Indigo `#6366f1`, Violet `#8b5cf6`, Cyan `#06b6d4`).
- ✅ **Responsive Layout**: Designed with CSS Flexbox and Grid. Fully responsive across desktops, tablets, and mobile phones.
- ✅ **Typography & Spacing**: Plus Jakarta Sans typography with clean size hierarchy and strict `box-sizing: border-box`.
